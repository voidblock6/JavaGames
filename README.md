# Numerical High

Numerical high is a game you can see as higher or lower but balatro style, the aim of the game is to guess the right number with rounds getting progressively harder.  The game has upgrades & debuffs which create depth, some plays are risky but earn you more points, some upgrades may slow down your progress down right now but earn you more in the long run. 

# Status
The game is still in pretty early development with many many more things planned to be added.

# Development stack
* Language: Java
* Framework: libGDX
* Graphics: libresprit
